# Personal Wiki With Local Gemma

This document outlines the requirements for building a CLI-based personal wiki using a local open-weight Gemma model and Retrieval-Augmented Generation (RAG). Students must implement a harness that supports three distinct modes: chat, ask, and search, ensuring the entire system functions offline.

## The assignment brief: `Assignment 4_ Personal Wiki with Local Gemma + RAG.md`

- Build a CLI and harness to interact with local data using a local open-weight Gemma model.
- Implement three required modes: Chat (personal assistant), Ask (factual research), and Search (inspect original sources).
- The system must function entirely offline for the final demonstration.
- The project requires a personal wiki in Obsidian with at least three original sources and linked pages.
- Students must provide evidence of four ask-mode tests: three answerable questions and one question with insufficient evidence.
- The README must include device specs, model/version, quantization, and measured memory use and response time.
- The harness must manage conversation context, tool calls, prompt assembly, and citation checks.
- The project is graded on deliverable quality, testing & evaluation, and working results.
